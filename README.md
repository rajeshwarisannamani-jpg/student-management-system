# Student Management System

A beginner-friendly Python command-line application to manage student records.

## Features
- Add student records
- View all records
- Search by name or USN/student ID
- Update a record
- Delete a record with confirmation
- Save records persistently in `students.json`
- Prevent duplicate student IDs

## Requirements
- Python 3 (standard library only; no extra packages needed)

## Run
1. Open this folder in Visual Studio Code.
2. Open Terminal → New Terminal.
3. Run `python student_management.py` (Windows alternative: `py student_management.py`).
4. Follow the menu and enter an option from 1 to 6.

The program creates `students.json` in this folder when a record is saved.

## Demo test ideas
Add a sample student, view all students, search for the student, update the course, then delete the sample record if desired.
